Las investigaciones 1 y 3 incluidas son revisiones de fuentes primarias hechas para la entrega final. El registro no permite reconstruir conversaciones históricas faltantes, ni acredita entrevistas, pruebas en una fecha anterior o validación del equipo que no haya quedado documentada.

La [auditoría previa](auditoria-entrega.md) registra el estado antes de esta integración. Para actualizar datos se regenera el derivado, se revisa el reporte y se ejecutan los checks antes de publicar.
