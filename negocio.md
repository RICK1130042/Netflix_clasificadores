# Objetivo de negocio

La persona responsable de retención usa el tablero para seleccionar segmentos y candidatos para una prueba de contacto. Propuesta de operación: revisar cada lunes con apoyo de un analista. Antes de activar una campaña se confirma que la población sea elegible y que las variables precedan a la cancelación.

**Línea base descriptiva.** El archivo activo tiene 2,515 abandonos entre 4,990 filas (50.4%). La fuente original tiene 2,515 entre 5,000 (50.3%). Son proporciones del dataset y no tasas mensuales verificadas.

**Meta propuesta para un piloto.** Revisar hasta el 20% de la población elegible y detectar al menos el 70% de quienes cancelen durante el horizonte que acuerde el equipo. La meta toma como referencia el ejemplo docente. Su logro se debe medir en una cohorte temporal independiente. Ordenar por score antes de observar el abandono, dividir los abandonos capturados entre los observados y reportar tanto numerador como denominador. La reducción de abandono se evalúa por separado con un grupo de control.
