# 03 · Acceso por roles

Revisión bibliográfica realizada para la entrega final. Wayne Jansen (1998), [A Revised Model for Role Based Access Control](https://csrc.nist.gov/pubs/ir/6192/final), NIST IR 6192. En RBAC, los roles organizativos median el acceso a recursos.

**Decisión aplicada.** Gerencia recibe vistas agregadas y el panel ejecutivo de campañas. El rol analista tiene permisos adicionales para predicción, CRM y exportaciones. La [matriz](../acceso.md) documenta cada límite y [las pruebas](../tests/test_roles.py) comprueban los controles de servidor. No se atribuye esta revisión a la exposición original de octubre.
